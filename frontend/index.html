About this demo
Static frontend calling the GenLayer Studio RPC directly from the browser (CORS-verified). Reads use readContract; writes go through either a connected browser wallet (window.ethereum) or a locally generated account (stored in your browser's localStorage — studionet needs no gas, verified with a 0-balance account). Contract source: interfluve-wav/ArtistLedger.
